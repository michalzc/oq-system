Initiative

The character sheet's Combat tab and the NPC sheet's Combat section offer skills and special abilities with roll formulas as initiative actions. Initiative uses the selected action's value plus the adjacent integer modifier, without the action's skill-roll modifiers. No dice are rolled.

Combat Tracker

Declaration

Every encounter begins with Round 1 - Declaration and no active participant. Owners choose actions and signed initiative modifiers in the tracker or actor sheet. The GM can edit all participants. Tracker changes also save the actor sheet's defaults.

In the tracker, each participant has a Declared action list, showing actions as Name (value), and an Initiative modifier field, which accepts whole numbers such as +5 or -10. Participants you do not own are shown read-only.

Execution

The GM clicks Start round to freeze each participant's action, modifier and total, sort initiative descending, and begin the first eligible turn. Changes to the actor sheet during execution apply to the next declaration phase. Declaring an action records intent; it does not restrict later actions or change skill-roll modifiers.

Ending the last eligible turn opens the next round's declaration phase automatically. The GM's Next Round control does the same. Previous Turn stays within the current round; reopening earlier declarations is not supported.

Controls

  • GM during declaration: Start round and End Encounter.
  • GM during execution: Previous Turn, Next Turn, Next Round and End Encounter.
  • Players, on their own turn: Previous Turn and End Turn.

Core initiative rolling is not used: the tracker has no roll buttons, and the context menus have no reset, clear or re-roll initiative options. Initiative cannot be edited by hand during execution.

Special cases

Blank or deleted actions use modifier-only initiative. Actorless participants use zero. Participants added during execution are shown as Awaiting next round and join the next round. Foundry's defeated-participant skipping applies, and the GM cannot start a round without any eligible participants. A connected GM and the Query Users permission are required for player tracker edits and turn advancement.
