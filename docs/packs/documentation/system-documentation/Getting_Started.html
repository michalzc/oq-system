Compendia

The system ships with these compendia, in the OpenQuest SRD folder:

  • Skills: the basic skills from the SRD. Most of them are marked as defaults for new actors.
  • Spells: Personal Magic, Divine Magic and Sorcery spells.
  • Equipment: weapons, armour, ammunition and other gear.
  • Documentation: this journal and the Spells Results tables linked from spell descriptions.
  • SRD Bestiary: SRD creatures as journal pages.

New Actors

Default items

A newly created actor receives copies of the items marked as defaults for its type. Items are added only when the actor is created empty; imported and duplicated actors keep the items they already have.

  • The source is the Default Items Compendium setting, the Skills compendium by default. Choose No Default Compendium to start with empty actors.
  • With Default Items from World enabled, marked world items are added too. A world item imported from the compendium replaces its original, so you can customise a default skill by importing and editing it.

To mark an item, open its sheet as a GM and choose Default for New Actors from the header menu. Tick Player Character, Monster/NPC or both. The option is available only for items that no actor owns: world items and items in an unlocked compendium.

Token defaults

New actors get prototype token defaults, unless the creation data already sets them:

  • All actors: name and bars displayed Always for Owner, Hit Points as the first bar and Magic Points as the second.
  • Player Characters: linked to the actor, vision enabled, Friendly disposition.

System Settings

  • Coins Configuration (requires reload): the coins used for money and item costs, written as Name (ABBR) = multiplier entries separated by commas. The default is Gold Ducats (GD) = 20, Silver Pieces (SP) = 1, Copper Pennies (CP) = 0.1, Lead Bits (LB) = 0.02. Item costs are entered in units of the coin with multiplier 1. Names may contain only letters, digits, spaces and underscores; entries that cannot be read are skipped.
  • Default Items Compendium: see Default items above.
  • Default Items from World: see Default items above.

Recommended core settings

The system changes the defaults of two core settings. Values already saved by users are kept, and Reset Defaults restores these values:

  • Left-Click to Release Objects: on.
  • Automatic Token Rotation: off.
